State Management

Pemisahan siklus hidup aplikasi.

Data-Driven Approach: Komponen dievaluasi secara berkala saat Update Loop tinggi.
1. App State (Framework Routines)
SDL3 + Vulkan Lifecycle
Mengendalikan rutinitas inti runtime aplikasi natif dari nol.
  • Init State: Alokasi Swapchain GPU, driver jaringan, pendaftaran plugin mod.
  • Update & Render State: Sinkronisasi loop penangkapan input & pengiriman command buffer.
  • Cleanup State: Operasi DeviceWaitIdle dan de-alokasi buffer grafis VRAM secara bersih.
2. Game State (Match Sessions)
Global Rules Loop
Mengatur regulasi giliran faksi serta sinkronisasi data pemain.
  • Player Turn State: Aktivasi UI interaktif dan pemrosesan ekonomi berkala.
  • AI Turn State: Blokir input manusia, pemicuan Behavior Trees taktis unit musuh.
  • Paused State: Penguncian simulasi, overlay pengaturan menu modular.
3. Entity State (Local Objects)
Pure Data Component
Disimpan murni sebagai sekumpulan data mentah yang diatur oleh sistem eksekusi (ECS).
  • Idle State: Loop animasi statis, menunggu instruksi.
  • Moving State: Pembaruan parameter koordinat grid heksagon & poin pergerakan.
  • Combat State: Kalkulasi damage (Combat Resolution) & sinkronisasi audio dan animasi tembakan.
