UI/UX Canvas

Desain Antarmuka Taktis Berbasis Sinkronisasi Menggunakan Pola Kerja IMGUI

Karena dikembangkan dari nol menggunakan SDL3 dan Vulkan 1.3, antarmuka game ini membuang total pola retain-mode konvensional, bermigrasi penuh ke Immediate Mode UI (IMGUI):

  • Nihil Kebocoran Memori: Widget dievaluasi dan dirender secara sinkron pada siklus Render State frame buffer tanpa menyimpan hierarki objek statis di RAM.
  • Efisiensi Modding Canvas: Mempermudah pembentukan editor kustom dalam game; menyusun jendela modifikasi baru hanya memerlukan beberapa baris fungsi prosedural C.

Mengadopsi estetika visual kartografi abad pertengahan klasik (Stylized Mappa Mundi with Grained Shades) untuk memperkuat imersi pertempuran makro:

  • Skema Antarmuka Terpadu: Warna penanda faksi berbaur dengan tekstur kertas navigasi bahari kuno, menciptakan ilusi dokumen sejarah yang hidup di layar pemain.

Tata letak taktis mengadopsi rancangan klasik yang familier bagi veteran genre strategi papan (terinspirasi dari World Conqueror 4 layout):

  • Top Resource Bar: Pemantauan real-time untuk variabel aset Economic, Industry, dan Research serta akses instan ke Paused State.
  • Contextual Components: Panel Tile Info (medan perang) dan perluasan tombol Unit Info hanya akan muncul via IMGUI ketika koordinat heksagon diklik aktif.
