Technical Requirements

Arsitektur Pemrograman Sistem Tingkat Rendah Agnostik Terhadap Vendor

Engineering Core

[ ISO C17 / C++20 Standard ]

Inti simulasi taktis (Game Loop) dibangun menggunakan standar C17 murni untuk de-alokasi memori deterministik yang cepat, dikombinasikan dengan fitur modern C++20 untuk manajemen struktur data modular tanpa ekstensi spesifik kompilator vendor.

[ SDL3 Windowing & OS Abstraction ]

Menggunakan SDL3 sebagai satu-satunya dependensi lintas platform. Menangani penangkapan input events (mouse/sentuhan), pembuatan permukaan jendela, dan subsistem audio Ogg Vorbis secara seragam tanpa dependensi eksternal komersial.

[ Pure Vulkan 1.3 Graphics API ]

Grafis dikunci pada standardisasi fitur inti Vulkan 1.3. Memanfaatkan penyerahan multithreading command buffer secara langsung untuk menjamin portabilitas rendering yang konsisten baik pada GPU desktop maupun perangkat seluler lama.

Compiler Pipeline: GCC / Clang / MSVC Standard Compliant

Asset Pipeline

[ Open-Standard SVG Level Maker ]

Pembuatan peta menggunakan dokumen format SVG (Scalable Vector Graphics) standar W3C. Skrip kustom Python murni mengekstraksi parameter nodal koordinat ubin heksagon dan kode warna medan (terrain color) secara langsung menjadi data tekstual JSON.

[ 2D Texture Array Containers (.ktx2) ]

Aset visual 2D diubah menjadi kontainer terbuka 2D Texture Array (.ktx2) via toktx Khronos. Dimuat sebagai satu objek VkImage dengan banyak lapisan, memungkinkan fragment shader mengindeks aset tekstur secara langsung tanpa proses binding berulang.

[ Unified Single Shader Engine ]

Sistem rendering hanya menggunakan satu pasang biner shader SPIR-V (1 Vertex & 1 Fragment). Menggambar seluruh elemen visual sebagai bentuk quad 2D via Push Constants, mempercepat pemrosesan filter butiran perkamen secara prosedural.

Data Integrity: Zero Executable Binary Mod Formats
