Telemetry & Privacy

Keseimbangan Pengumpulan Statistik Komunitas dengan Proteksi Data Pengguna

Sistem dirancang transparan. Data pemakaian dikembalikan penuh ke komunitas untuk membantu kreator melakukan penyeimbangan mekanik (game balancing) skenario buatan mereka.

❖ Completion Rate (Win/Loss Ratio)

Menampilkan persentase rasio kemenangan pemain pada metadata unduhan mod, mempermudah pemain mengukur tingkat kesulitan skenario secara instan.

❖ Average Turn to Victory

Metrik numerik rata-rata jumlah giliran (turn count) komunitas menyelesaikan misi, berfungsi sebagai estimasi durasi skenario taktis.

❖ Unit Lethality Index

Daftar peringkat unit kustom paling efektif di medan tempur berdasarkan rasio kill/death tertinggi untuk mendeteksi ketidakseimbangan unit.

Privasi mutlak dan penanganan I/O yang aman dikunci dari dalam program inti demi menjaga integritas data perangkat keras pemain.

❖ Absolute Anonymization

Data transmisi murni berupa parameter numerik mekanik game (ID Skenario, Turn, Status Akhir). Sistem dilarang merekam data pribadi seperti IP Address, lokasi, atau Hardware IDs.

❖ Opt-In Transparency Toggle

Di dalam menu utama atau Paused State, pemain diberi kendali penuh lewat tombol GUI untuk mematikan fitur telemetri ini jika ingin bermain dalam mode privat murni.

❖ Zero Executable Formats (JSON I/O)

Peladen publik hanya menerima kiriman data teks mentah format JSON. Berkas divalidasi ketat untuk memotong potensi serangan injeksi biner berbahaya.
